## Requisitos
**RF-AG-01 — Identificación de la propiedad.** Antes de ejecutar cualquier herramienta, el agente determina la propiedad (glamping o departamento concreto) por código de reserva, nombre, dirección, contexto de la conversación o preguntando. *Criterios:* (a) ninguna herramienta que requiera `propiedad_id` se invoca con el campo vacío; (b) ante ambigüedad entre dos o más propiedades, el agente pregunta con una lista de opciones (RF-GW-02) en lugar de asumir; (c) la propiedad resuelta se persiste en el contexto de la conversación. *Árbitro:* `tests/agente/test_enrutador.py` con 20 conversaciones sintéticas etiquetadas.
**RF-AG-03 — Exposición selectiva de herramientas.** Expone a Claude solo las herramientas pertinentes a la propiedad y al rol del interlocutor (allowlist por acción, §3 de este PRD). *Criterios:* (a) un huésped nunca ve herramientas de ventas; (b) un vendedor nunca ve herramientas de reservas; (c) el conjunto expuesto queda registrado en la traza de la llamada. *Árbitro:* `tests/agente/test_allowlist_herramientas.py`.
**RF-AG-08 — Planificador idempotente.** Una tarea programada pide las llegadas del día y envía las instrucciones. *Criterios:* (a) un reinicio no repite el envío (`INV_ENVIO_UNICO`); (b) si falla, se reintenta sin duplicar. *Árbitro:* `tests/agente/test_planificador.py`.

## Tablas de esta sala
```sql
CREATE TABLE agente.conversaciones (
  conversacion_id  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  identidad_token  text NOT NULL,
  canal            text NOT NULL CHECK (canal IN ('huespedes','vendedores')),
  propiedad_id     text,
  estado           text NOT NULL DEFAULT 'activa' CHECK (estado IN ('activa','handoff','cerrada')),
  modo             text NOT NULL DEFAULT 'activo' CHECK (modo IN ('activo','silencio')),
  resultado        text CHECK (resultado IN ('resuelta','handoff','abandonada')),
  abstenciones_seguidas integer NOT NULL DEFAULT 0 CHECK (abstenciones_seguidas >= 0),
  ventana_24h_hasta timestamptz,
  creada           timestamptz NOT NULL DEFAULT now(),
  actualizada      timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE agente.mensajes (
  mensaje_id       text PRIMARY KEY,
  conversacion_id  uuid NOT NULL REFERENCES agente.conversaciones(conversacion_id),
  direccion        text NOT NULL CHECK (direccion IN ('in','out')),
  tipo             text NOT NULL,
  contenido_token  text NOT NULL,
  traza_id         text,
  instante         timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE agente.envios_programados (
  codigo_reserva   text NOT NULL,
  plantilla        text NOT NULL,
  fecha            date NOT NULL,
  mensaje_id       text,
  creado_en        timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (codigo_reserva, plantilla, fecha)
);

CREATE TABLE agente.cache_semantico (
  hash_consulta    text PRIMARY KEY,
  embedding        vector(1024) NOT NULL,
  respuesta        text NOT NULL,
  creado_en        timestamptz NOT NULL DEFAULT now(),
  expira_en        timestamptz NOT NULL
);
```

## Invariantes
| Código | Predicado | Mecanismo obligatorio |
| :--- | :--- | :--- |
| `INV_ALLOWLIST_POR_ACCION` | `ejecutada(h, rol) ⇒ h ∈ allowlist(rol)` | `seguridad.autorizar` dentro de cada herramienta, no solo al exponerla. |
| `INV_CACHE_SIN_PRECIOS` | `servida_de_cache(r) ⇒ ¬contiene(r, precio ∨ disponibilidad)` | Filtro antes de escribir en el caché. |
| `INV_ENVIO_UNICO` | `∣envios(reserva, plantilla, dia)∣ ≤ 1` | `INSERT ... ON CONFLICT DO NOTHING` en `agente.envios_programados` antes de enviar. |
| `INV_NO_LO_SE` | `afirma(precio ∨ politica ∨ disponibilidad) ⇒ ∃ soporte(chunk ∨ herramienta)` | Umbral `umbral_suficiente` y suite `rag`. |
| `INV_PII_FUERA_DEL_MODELO` | `∀ v ∈ PII(m) : v ∉ payload ∪ logs ∪ trazas ∪ historial` | Tokenización antes de cada llamada; rehidratación solo en la salida. |
| `INV_PROPIEDAD_RESUELTA` | `requiere_propiedad(h) ∧ invocada(h) ⇒ propiedad_id ≠ ∅` | Validación en el agente antes de llamar. |
| `INV_SIN_FUGA_ENTRE_PROPIEDADES` | `∀ c ∈ recuperados(A) : propiedad(c) ∈ {A, global}` | RLS con `SET LOCAL app.propiedad_id` dentro de cada transacción. |
