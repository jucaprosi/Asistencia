## Entregables
Entregables: rutas `/buscar` y `/comparar`, y `resolver_contacto` para que el agente reciba propiedad, fechas y huéspedes. Corre contra `FakePMS`, así que no espera ADR-0007.

## Requisitos
**RF-WEB-02 — Búsqueda.** Por fechas, huéspedes, tipo y zona. *Criterios:* (a) precio y disponibilidad salen del PMS en cada consulta (`INV_WEB_PRECIO_EN_VIVO`); (b) si el PMS falla no se muestran precios y se ofrece WhatsApp. *Árbitro:* `tests/web_huespedes/test_busqueda.py`.
**RF-WEB-03 — Comparación.** Hasta tres propiedades propias lado a lado. *Criterios:* (a) muestra capacidad, zona, comodidades y total; (b) no incluye negocios de terceros. *Árbitro:* `tests/web_huespedes/test_busqueda.py`.
**RF-WEB-04 — Paso a WhatsApp.** La reserva termina en WhatsApp con un código de contexto. *Criterios:* (a) el enlace no lleva datos personales (`INV_WEB_SIN_PII`); (b) el agente resuelve propiedad, fechas y huéspedes; (c) la web no reserva (`INV_WEB_SOLO_LECTURA`). *Árbitro:* `tests/web_huespedes/test_contacto.py`.

## Tablas de esta sala
```sql
CREATE TABLE web.enlaces_contacto (
  codigo           text PRIMARY KEY CHECK (codigo ~ '^W-[A-Z0-9]{8}$'),
  propiedad_id     text NOT NULL,
  desde            date,
  hasta            date,
  huespedes        integer CHECK (huespedes >= 1),
  creado_en        timestamptz NOT NULL DEFAULT now(),
  expira_en        timestamptz NOT NULL,
  CHECK (hasta IS NULL OR hasta > desde)
);

CREATE TABLE web.limites_ip (
  ip_hash          text NOT NULL,
  ventana          timestamptz NOT NULL,
  conteo           integer NOT NULL DEFAULT 1,
  PRIMARY KEY (ip_hash, ventana)
);
```

## Invariantes
| Código | Predicado | Mecanismo obligatorio |
| :--- | :--- | :--- |
| `INV_WEB_LIMITE_POR_IP` | `conteo(ip, minuto) > limite ⇒ ∣llamadas_pms∣ = 0` | `INSERT ... ON CONFLICT DO UPDATE` en `web.limites_ip` antes de llamar al PMS. |
| `INV_WEB_PRECIO_EN_VIVO` | `mostrado(precio, t) ⇒ precio = cotizar(t)` | `Cache-Control: no-store` en `/buscar` y `/comparar`, sin caché de servidor. |
| `INV_WEB_SIN_PII` | `∀ f ∈ tablas(web) ∪ enlaces ∪ logs : PII(f) = ∅` | Sin formularios de datos; código aleatorio `W-` con `secrets`; IP solo como HMAC con secreto. |
| `INV_WEB_SOLO_LECTURA` | `∀ r ∈ rutas(web) : efectos_pms(r) = ∅` | La compuerta recibe un puerto de `pms` con solo `consultar_disponibilidad` y `cotizar`. |
